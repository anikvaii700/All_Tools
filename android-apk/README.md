# The MoSaFa StudyMate BD & Tools — Android APK সোর্স ও ইনস্টলেশন প্যাকেজ 📱

এই ডিরেক্টরিতে **The MoSaFa StudyMate BD** এবং **The MoSaFa Tools** পোর্টালটির সম্পূর্ণ অ্যান্ড্রয়েড অ্যাপ (APK) সোর্স কোড ও নির্দেশনাবলি দেওয়া হয়েছে।

---

## 🚀 মোবাইলে APK ইনস্টল করার ৩টি সহজ উপায়

### উপায় ১: মোবাইল থেকে সরাসরি ১-ক্লিকে ইনস্টল (WebAPK / PWA) — [সবচেয়ে দ্রুত ও সহজ]
আপনার কোনো কম্পিউটার বা অ্যান্ড্রয়েড স্টুডিওর প্রয়োজন নেই:
1. আপনার অ্যান্ড্রয়েড ফোনের **Google Chrome** ব্রাউজারে সাইটের লিঙ্কটি খুলুন:  
   👉 `https://ais-pre-vzob6g5trhnzc2w7qmf6to-580416772203.asia-southeast1.run.app`
2. স্ক্রিনের ওপরে বা নিচে থাকা **"📲 মোবাইল অ্যাপ নামান"** বাটনে চাপুন (অথবা Chrome-এর ওপরের ডানদিকের ৩-ডট `⋮` মেনু চাপুন)।
3. **"Install app"** বা **"Add to Home screen"** নির্বাচন করে **"Install"** চাপুন।
4. সাথে সাথে গুগল ক্রোম অ্যান্ড্রয়েডের নেটিভ **WebAPK** তৈরি করে আপনার মোবাইলের হোম স্ক্রিন ও অ্যাপ ড্রয়ারে মূল আইকনসহ সম্পূর্ণ অ্যাপ হিসেবে ইনস্টল করে দেবে।
5. এটি ইন্টারনেট ছাড়াই অফলাইন ক্যাশ সমর্থন করে এবং ফুলস্ক্রিনে ঠিক সাধারণ অ্যান্ড্রয়েড অ্যাপের মতো কাজ করে।

### উপায় ২: PWABuilder দিয়ে সরাসরি প্রস্তুত `.apk` ফাইল ডাউনলোড (১ মিনিট)
গুগল ও মাইক্রোসফটের অফিসিয়াল **PWABuilder** ইঞ্জিন ব্যবহার করে সরাসরি সাইন্ড `.apk` ফাইল তৈরি করা যায়:
1. যেকোনো ব্রাউজারে যান: `https://www.pwabuilder.com`
2. ইনপুট বক্সে আপনার লাইভ লিঙ্কটি দিন:  
   `https://ais-pre-vzob6g5trhnzc2w7qmf6to-580416772203.asia-southeast1.run.app`
3. **"Start"** বাটনে চাপুন।
4. **"Package for Android"** অপশনটিতে ক্লিক করুন।
5. **"Generate APK / Package"** বাটনে ক্লিক করলেই সরাসরি মোবাইলে ইনস্টলযোগ্য সাইন্ড `.apk` ফাইল ডাউনলোড হয়ে যাবে!
6. ফাইলটি আপনার ফোনে পাঠিয়ে ইনস্টল (Install from Unknown Sources allow করে) করে নিন।

---

### উপায় ৩: এই প্রজেক্টটি Android Studio-তে খুলে সরাসরি APK তৈরি
আপনি যদি নিজে অ্যান্ড্রয়েড স্টুডিও দিয়ে বিল্ড করতে চান:
1. এই ফোল্ডারটি (`android-apk`) অথবা `public/The-MoSaFa-StudyMate-Android-Project.zip` ডাউনলোড করুন।
2. আপনার কম্পিউটারের **Android Studio** ওপেন করে **Open an Existing Project** থেকে এই ফোল্ডারটি নির্বাচন করুন।
3. Gradle Sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন (স্বয়ংক্রিয়ভাবে হবে)।
4. মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)** চাপুন।
5. কয়েক সেকেন্ডের মধ্যে `app/build/outputs/apk/debug/app-debug.apk` তৈরি হয়ে যাবে।
6. আপনার মোবাইল ফোনটি USB ক্যাবল বা Wi-Fi দিয়ে যুক্ত করে সবুজ **Run ▶️** বাটনে চাপলে সরাসরি আপনার ফোনে অ্যাপটি ইনস্টল হয়ে চালু হয়ে যাবে!

## 📂 এই ডিরেক্টরির ফাইল পরিচিতি
- `app/src/main/AndroidManifest.xml` — ইন্টারনেট, ক্যামেরা ও ফাইল আপলোডের পারমিশন কনফিগারেশন।
- `app/src/main/java/com/mosafa/studymate/MainActivity.kt` — আধুনিক Kotlin WebView ইঞ্জিন (ক্যামেরা দিয়ে অঙ্ক বা বইয়ের ছবি আপলোড, ফুলস্ক্রিন, ডাউনলোড সমর্থন)।
- `app/build.gradle` — অ্যান্ড্রয়েড SDK 34 এবং ডিপেনডেন্সিসমূহ।
- `.github/workflows/build-apk.yml` — গিটহাবে পুশ করলে স্বয়ংক্রিয়ভাবে APK তৈরি করার GitHub Actions স্ক্রিপ্ট।
